# AI Hand Gesture Volume Controller 🎛️🤖

This project uses Computer Vision and Hand Tracking to control the system volume using hand gestures in real time.

Using a webcam, the program detects the distance between the thumb and index finger and adjusts the system volume accordingly.

---

## 🚀 Features

- Real-time hand tracking
- Gesture-based volume control
- Live webcam interface
- Volume percentage display
- Interactive volume bar

---

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- Pycaw
